# ハードウェア構成

## 接続

| ESP32 ピン(例) | LT86104SX 側 | 備考 |
|---|---|---|
| GPIO21 (SDA) | SDA | 4.7 kΩ プルアップ(3.3V) |
| GPIO22 (SCL) | SCL | 同上。100 kHz から始め、安定したら 400 kHz |
| GPIO4 | RESET_N | 起動時に Low → High |
| GPIO5 | INT | 入力信号変化 / HPD 通知(プルアップ) |
| GND | GND | 共通 |

ピン番号は例です。使用する ESP32 ボードに合わせて変更してください。

## 電源

- LT86104SX はコア用の低電圧と I/O 用 3.3V の複数電源が必要です。正確な電圧・投入順序はデータシートで確認してください。
- 各 HDMI 出力の +5V ピンにはソース側の役割として 5V を供給します(合計 4 系統、各 50 mA 程度)。
- ESP32 の Wi-Fi ピーク電流(約 500 mA)を考慮し、3.3V レギュレータは 1 A 級を推奨します。

## TMDS 配線

- 差動 100 Ω、ペア内長差 ±5 mil 以内、AC 結合なし(HDMI は DC 結合)
- コネクタ直近に ESD 保護素子を配置
- 自作基板で TMDS を引く場合は 4 層以上を推奨。難しければ **市販の LT86104 搭載スプリッタ基板を流用し、I2C だけ引き出す** ことを推奨します。

## 市販基板流用の手順

1. LT86104SX/SXE 搭載の 1×4 スプリッタ(2,000〜4,000 円程度)を入手
2. 基板上の MCU(多くは 8051 系)を取り外す、または I2C バスをアイドルにする
3. SDA/SCL/RESET/GND を ESP32 に接続
4. 基板の 5V 電源を ESP32 と共用

## 注意

- LT86104SX のレジスタマップは公開されていません。Lontium または代理店(L2Tek 等)から NDA でデータシートと初期化シーケンスを入手する必要があります。
- HDCP コンテンツを扱う場合はライセンス上の制約があります。
