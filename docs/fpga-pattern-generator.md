# FPGA 4 出力テストパターン発生器

mp4 を再生するのではなく、**FPGA のロジックでテストパターンを生成し、HDMI 4 本を独立したタイミングで出力する**装置。
1 台で完結し、分配器も外部ソースも使わない。

## 出せるもの

- 解像度: 1080p / 720p / 480p
- フレームレート: 29.97p / 59.94p / 30p / 60p(4 出力それぞれに別のモードを設定できる)
- 画面内容: 75% カラーバー、1 フレーム 1 ステップで動く白いボックス(コマ落ち検出用)、
  下部グレースケール、1 ピクセルの白い外枠(オーバースキャン検出用)、
  「OUT1 1080p 59.94」ラベル、6 桁フレームカウンタ、hh:mm:ss:ff タイムコード
- 音声: なし(必要なら ADV7513 の I2S に正弦波を入れる拡張が可能)

シミュレーションで得た 480p フレーム:

```
sim/ で make MODE=9 FRAME=2 -> frame.ppm
```

## 構成

```
                +------------------------- Artix-7 -------------------------+
100 MHz OSC --->| MMCM x4 (各出力の正確なピクセルクロック)                     |
                |  ch0: timing -> counter -> pattern -> 24bit RGB + DE/HS/VS |--> ADV7513 #1 --> HDMI OUT1
                |  ch1:                     "                                |--> ADV7513 #2 --> HDMI OUT2
                |  ch2:                     "                                |--> ADV7513 #3 --> HDMI OUT3
                |  ch3:                     "                                |--> ADV7513 #4 --> HDMI OUT4
                |  I2C master x2 (ADV7513 初期化: 0x39 / 0x3D を 2 バスに振り分け) |
                +------------------------------------------------------------+
```

- 各チャネルは完全に独立したクロック域で動く。OUT1=59.94p、OUT2=60p のような組み合わせも同時に出せる。
- HDMI の TMDS 化は ADV7513(HDMI 1.4 送信 IC、165 MHz まで、公開データシート・Linux ドライバあり)に任せ、
  FPGA は 24bit パラレル RGB を出すだけ。FPGA から直接 TMDS を出す方式は Artix-7 の HR バンクでは
  1080p60(1.485 Gbps)が規格外になるため採らない。

## チップ選定

| 部品 | 選定 | 理由 |
|---|---|---|
| FPGA | Xilinx Artix-7 XC7A35T 以上(FGG484 推奨) | 無償の Vivado で使える、MMCM 5 個以上、I/O が足りる |
| HDMI 送信 | ADI ADV7513 ×4 | 1080p60 対応、データシート公開、Linux に adv7511 ドライバがあり設定値が確認できる |
| 発振器 | 100 MHz ×1 | MMCM で 6 種類のピクセルクロックを誤差 1 ppm 以内で生成 |

### 代替

- HDMI 送信を **ITE IT66121** にすると安価だが、設定手順の公開資料が少ない。
- **Lattice ECP5 + オープンツール(Yosys/nextpnr)** でも可。PLL の分数分周がないので 1/1.001 系の
  クロックは外付け発振器(Si5351 など)が必要。
- 4 出力を 1 つの FPGA に入れず、**1 出力 = 小型 FPGA 1 個**(Artix-7 XC7A15T / Gowin GW1N + ADV7513)を
  4 枚並べる構成も、基板が単純になり最小構成として有効。

## ピン数の見積もり(XC7A35T-FGG484: 250 I/O)

| 信号 | 本数 |
|---|---|
| RGB 24bit ×4 | 96 |
| CLK / DE / HS / VS ×4 | 16 |
| I2C ×2 バス | 4 |
| HPD ×4 | 4 |
| 100 MHz、リセット、LED | 6 |
| 合計 | 約 126 |

I/O が足りない小型パッケージ(FTG256 = 170 I/O)でも収まる。さらに減らしたい場合は ADV7513 の
DDR 入力モード(12bit ×2 エッジ)を使えば RGB は 48 本になる。

## クロック生成

MMCME2_BASE(100 MHz 入力)の設定。`hdl/video_modes.vh` の関数で MODE から自動選択される。

| ピクセルクロック | 用途 | DIVCLK | MULT_F | DIVIDE_F | 誤差 |
|---|---|---|---|---|---|
| 148.5 MHz | 1080p60 | 4 | 37.125 | 6.25 | 0 |
| 148.352 MHz | 1080p59.94 | 7 | 50.625 | 4.875 | 0 |
| 74.25 MHz | 1080p30 / 720p60 / 720p30 | 4 | 37.125 | 12.5 | 0 |
| 74.176 MHz | 1080p29.97 / 720p59.94 / 720p29.97 | 6 | 50.625 | 11.375 | 0 |
| 27.027 MHz | 480p60 | 1 | 6.25 | 23.125 | +1 ppm |
| 27.0 MHz | 480p59.94 | 1 | 6.75 | 25.0 | 0 |

## モード一覧

| MODE | 解像度 | fps | H total × V total | 備考 |
|---|---|---|---|---|
| 0 / 1 | 1080p | 60 / 59.94 | 2200 × 1125 | CEA-861 VIC 16 |
| 2 / 3 | 1080p | 30 / 29.97 | 2200 × 1125 | VIC 34 |
| 4 / 5 | 720p | 60 / 59.94 | 1650 × 750 | VIC 4 |
| 6 / 7 | 720p | 30 / 29.97 | 3300 × 750 | VIC 62 |
| 8 / 9 | 480p | 60 / 59.94 | 858 × 525 | VIC 2/3、負極性シンク |
| 10 / 11 | 480p | 30 / 29.97 | 1716 × 525 | **規格外**。受け付けないモニタがある |

各出力のモードは `hdl/top.v` の `MODE0..MODE3` パラメータで指定する(ビルド時固定)。

### 実行時にモードを切り替えたい場合

ピクセルクロックを変える必要があるため、次のいずれかが要る。v1 では対象外。

1. MMCM の DRP(動的再構成)で分周比を書き換える
2. 外付けクロックジェネレータ(Si5351A、I2C、分数 PLL)から 4 本のピクセルクロックを供給し、
   FPGA から I2C で周波数を書き換える。タイミングパラメータはレジスタ化して UART/DIP から選ぶ

## ADV7513 の接続

| ADV7513 ピン | 接続先 | 備考 |
|---|---|---|
| D[23:0] | hdmi_d[23:0](R=D[23:16], G=D[15:8], B=D[7:0]) | 入力 ID 0(24bit RGB 4:4:4) |
| CLK | hdmi_clk | ピクセルクロック。ODDR で出すのが望ましい |
| DE / HSYNC / VSYNC | hdmi_de / hdmi_hs / hdmi_vs | セパレートシンク |
| SCL / SDA | i2c_scl / i2c_sda | 4.7 kΩ プルアップ。1 バスに 2 台(PD/AD ピンで 0x39 と 0x3D) |
| PD/AD | GND または 3.3V | I2C アドレス選択 |
| HPD(出力) | hdmi_hpd | 未使用なら FPGA 側で 1 に固定 |
| TMDS 出力 | HDMI コネクタ | 100 Ω 差動、ESD 保護 |
| 電源 | 1.8V(コア/PLL/TMDS)、3.3V(I/O) | データシートの推奨回路に従う |

初期化レジスタは `hdl/adv7513_init.v` のテーブルにある(ADI Programming Guide の
クイックスタート値)。HPD を強制 High(0xD6=0xC0)にしているので、モニタ未接続でも出力を続ける。

## ビルドとシミュレーション

```
# シミュレーション (iverilog 12 以上)
cd sim && make MODE=1 FRAME=2      # 1080p 59.94 の 3 フレーム目を frame.ppm に保存

# Vivado
#  1. hdl/*.v, hdl/video_modes.vh, hdl/font8x16.mem をソースに追加 (top = top)
#  2. constraints/example.xdc をボードに合わせて編集して追加
#  3. top の MODE0..3 を Settings > General > Generics/Parameters で設定
#  4. Generate Bitstream
```

## 未実装・注意

- 音声出力なし。
- モード切替はビルド時固定。
- ADV7513 のレジスタ値は Programming Guide のクイックスタート値で、実機での確認が必要
  (特に 0x17 のシンク極性まわりと 0x18)。
- 同一 I2C バス上の 2 台は起動時に直列に初期化するが、HPD 再初期化が同時に走ると衝突する。
  ケーブルを同時に挿さない運用か、バスを 4 本に分けることで回避できる。
- 480p の 29.97/30(MODE 10/11)は CEA-861 にない規格外タイミング。
