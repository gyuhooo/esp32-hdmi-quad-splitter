# 実現可否の検討

## 要件

- Full HD(1920x1080)の映像を HDMI で 4 本出力する
- 最小構成にしたい
- ESP32 と LT86104SX を使う

## LT86104SX の能力

- HDMI 1.4 / DVI 1.0 準拠、1 入力 4 出力
- 3.4 Gbps/ch まで(1080p60 8bit は 1.485 Gbps/ch、Deep Color 12bit でも収まる)
- HDCP 1.4 リピータをハードウェアで処理
- EDID シャドウ RAM 内蔵(4 台の出力先の EDID を 1 つにまとめてソースへ提示)
- 受信側に CDR とアダプティブイコライザ、送信側にデエンファシス。長めのケーブルにも耐える

→ 1080p60 を 4 本へ複製する要件は IC 単体で満たす。

## ESP32 の能力

| 項目 | ESP32 / S3 | 1080p60 で必要な値 |
|---|---|---|
| 映像 I/F | なし(TMDS なし) | TMDS 3 レーン |
| 出力帯域 | 数十 Mbps 級(LCD/RGB パラレルで最大 80 MHz 程度) | 約 4.5 Gbps |
| フレームバッファ | PSRAM 最大 8〜16 MB | 1 フレーム 6 MB(RGB888) |

→ ESP32 は映像ソースになれない。役割は I2C による制御に限定する。

## 成立する構成

```
HDMI ソース ──> LT86104SX ──> HDMI×4
                  ^
                  | I2C
                ESP32
```

- 映像品質・解像度・フレームレート(29.97p / 59.94p / 30p / 60p)は **ソース側で決まる**。スプリッタは透過。
- ESP32 は起動時初期化、EDID 選択、入力信号検出、出力ポートの有効/無効、リモート操作を担当。

## 成立しない構成

- ESP32 が映像を生成して LT86104SX に入れる(帯域・I/F が無い)
- 4 本に異なる映像を出す(スプリッタは複製専用)

## 判断

**同一映像の 4 分配**であれば実現可能。ESP32 を組み合わせる価値は「ネットワーク経由での制御・監視」にある。
