# ESP32 からの制御

LT86104SX は I2C スレーブとして動作します。レジスタの詳細は非公開のため、ここでは制御の枠組みと、実機で確認すべき項目を示します。

## I2C アドレス

- 7bit アドレスはアドレス選択ピンで決まります。
- 起動後にバススキャンして確認してください(`firmware/` の雛形はスキャンを行います)。

## 初期化シーケンス(概要)

1. RESET_N を Low に 10 ms 以上保持し、High にする
2. 20 ms 待つ
3. チップ ID レジスタを読み、応答を確認
4. Lontium 提供の初期化テーブル(レジスタ/値の配列)を順に書く
5. EDID モードを設定(下記)
6. 出力ポートを有効化

## EDID の扱い

| モード | 内容 | 用途 |
|---|---|---|
| 内蔵固定 EDID | 1080p60 固定の EDID をソースへ提示 | テスト用途で最も安定。モニタ未接続でも出力可 |
| 最小公倍(mix) | 4 出力先の EDID から共通能力を合成 | 混在モニタ |
| 特定ポートをコピー | OUT1 の EDID をそのまま提示 | 基準モニタがある場合 |

テスト映像(1080/720/480、29.97p/59.94p/30p/60p)を通す場合は、固定 EDID に各モードの DTD を含めておくとソース側の切替が確実になります。

## 監視

- INT ピンまたはポーリングで「入力信号あり/なし」「各出力の HPD」を取得
- 取得した状態を Wi-Fi 経由(HTTP / WebSocket)で公開すると、OBS-RemoteControl などから確認できます
